Khái Niệm

MCP Là Gì?

Model Context Protocol (MCP) là một giao thức mã nguồn mở do Anthropic phát triển, đóng vai trò như một "cổng USB-C" tiêu chuẩn cho các mô hình ngôn ngữ lớn.

  • 🔌
    Kết nối hợp nhất: Thay vì xây dựng tích hợp riêng lẻ cho từng IDE và công cụ, MCP định nghĩa một chuẩn chung duy nhất.
  • 🛡️
    Bảo mật tối đa: Giữ quyền kiểm soát dữ liệu tại máy Client, không đẩy dữ liệu nhạy cảm trực tiếp lên đám mây không tin cậy.
  • 🔄
    Hai chiều linh hoạt: Cho phép AI đọc dữ liệu (Resources) và thực thi hành động (Tools).
Kiến Trúc

Kiến Trúc 3 Thành Phần

💻

1. MCP Host

Ứng dụng AI Client như Claude Desktop, Cursor, IDEs... Nơi người dùng trực tiếp tương tác và đưa ra yêu cầu.

🔄

2. MCP Client

Thành phần tích hợp bên trong Host, có nhiệm vụ thiết lập kết nối an toàn bảo mật, gửi/nhận lệnh JSON-RPC với Server.

⚙️

3. MCP Server

Các chương trình nhỏ chạy độc lập (NodeJS, Python...) cung cấp: Resources (dữ liệu), Tools (hành động) và Prompts (mẫu câu lệnh).

Luồng Xử Lý

Dữ Liệu Được Xử Lý Thế Nào?

1

Yêu cầu từ Người Dùng

User nhập prompt (Ví dụ: "Đọc file code trong thư mục slide"). Host nhận dạng ngữ cảnh và gửi tín hiệu qua Client.

2

Truy vấn MCP Server

Client chuyển đổi yêu cầu thành gói tin JSON-RPC, gửi đến MCP Server để truy xuất tài nguyên hoặc thực thi Tools.

3

Đóng gói Ngữ Cảnh

Server xử lý dưới máy local (hoặc gọi API ngoài) rồi trả dữ liệu thô về Client. Client tích hợp dữ liệu này thành Context.

4

Mô Hình Sinh Kết Quả

Client truyền Context đã làm giàu cho LLM. LLM trả về câu trả lời chính xác, thực tế cho người dùng.

Tại Sao MCP Thay Đổi Cuộc Chơi?

🚀 Hiệu năng tối đa

Sử dụng giao thức nhẹ JSON-RPC qua stdio hoặc SSE, hạn chế độ trễ và tối ưu luồng truyền tải thông tin cực kỳ mượt mà.

🧩 Khả năng tái sử dụng

Bạn chỉ cần viết MCP Server 1 lần duy nhất bằng Python hoặc TypeScript. Nó sẽ chạy ngay trên Claude Desktop, Cursor, và các IDE tương lai.

🛡️ Bảo mật cục bộ

Quyết định cấp quyền đọc ghi hoàn toàn nằm ở phía Client của người dùng. Dữ liệu nhạy cảm được xử lý cục bộ trước khi gửi lên LLM.
