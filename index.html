Khái Niệm

Figma MCP Là Gì?

Figma MCP Server là một cổng kết nối cho phép các mô hình AI (như Claude, Cursor) đọc trực tiếp cấu trúc thiết kế từ Figma Cloud API mà không cần người dùng phải export ảnh hay copy code thủ công.

  • 🎨
    Đọc hiểu cấu trúc thực tế: AI không chỉ nhìn hình ảnh, mà đọc được cấu trúc dạng cây (JSON AST) bao gồm Layer, Frame, Auto Layout, Typography và Màu sắc.
  • 🔑
    Token bảo mật cục bộ: Sử dụng FIGMA_API_KEY lưu trong biến môi trường cá nhân. AI Client tự gọi API an toàn, không lưu token vào repo hoặc chat.
  • 🎯
    Nhắm mục tiêu Node cụ thể: Truy xuất chính xác Frame được chọn thông qua link chứa node-id thay vì phải quét toàn bộ file thiết kế nặng nề.
Kiến Trúc

Kiến Trúc Figma MCP

🤖

1. AI Host Client

VS Code, Cursor, hoặc Codex nhận diện link Figma chứa fileKey và node-id từ câu lệnh (prompt) của người dùng.

⚙️

2. Figma MCP Server

Một tiến trình cục bộ (qua npx figma-developer-mcp) nhận lệnh JSON-RPC, dùng token môi trường gửi REST request.

☁️

3. Figma Cloud API

Server của Figma tiếp nhận request, trả về JSON của File/Node thiết kế. MCP Server lọc nhiễu rồi chuyển cho AI Client.

Xử Lý Dữ Liệu

Dữ Liệu Được Dịch Sang Code Như Thế Nào?

1

Phân Tích JSON Node Tree

Đọc cấu trúc cha-con từ Figma Node. Nhận dạng các layout flexbox (Figma Auto Layout) như direction, padding, gap để ánh xạ sang Flex CSS.

2

Ánh Xạ Màu Sắc & CSS Token

Đọc kênh màu RGB/RGBA của Figma, chuyển đổi thành Hex. Đối chiếu với file config hệ thống màu (ví dụ: tds-figma-color-mapping.md) để chọn màu chuẩn.

3

Dịch Thư Viện Component

AI nhận diện các Component Figma (Button, Input, Card) và so sánh với thư viện code có sẵn (TDS components) để reuse thay vì viết code HTML thô.

4

Sinh Code & Ghi Vào Repo

AI Client tiến hành sinh file component hoàn chỉnh (Angular, React, HTML) và ghi trực tiếp vào thư mục mã nguồn thông qua file write tools.

Ưu Điểm

Lợi Ích Của Luồng Figma MCP

⚡ Tốc độ & Độ chính xác

Loại bỏ khâu cắt ghép CSS thủ công. AI đọc chính xác kích thước pixel, gap spacing và layout flexbox giúp mã nguồn đồng bộ tuyệt đối với thiết kế Figma.

🛡️ An toàn thông tin

Token FIGMA_API_KEY được bảo mật hoàn toàn ở máy local. Figma MCP chạy qua stdio của terminal không cần qua máy chủ trung gian.

⚙️ Chuẩn hóa UI Component

Sự kết hợp giữa Figma Design Token và code giúp tránh việc sinh code rác. Sử dụng các component thiết kế tái sử dụng giúp mã nguồn sạch hơn.
